# Supermarket Sales Analysis with Data Analytics & AI

## Project Overview
This project analyzes supermarket historical sales data across different product branches and customer segments using Python, Data Analytics, and Machine Learning techniques.

## Key Objectives
- Clean and structure transaction records for analysis.
- Identify top-performing product categories and peak sales hours.
- Perform demographic and payment method analysis.
- Build a Machine Learning model to forecast sales revenue.

## Dataset
- **Dataset Name**: Supermarket Sales Dataset
- **Link**: https://www.kaggle.com/datasets/aungpyaeap/supermarket-sales

## Tech Stack & Libraries Used
- **Language**: Python 3.x
- **Libraries**: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`
- **Environment**: Google Colab / Jupyter Notebook

## How to Setup and Run
1. Download `YourName_SupermarketSalesAnalysis.ipynb`.
2. Open in Google Colab or Jupyter Notebook and run all cells sequentially.
